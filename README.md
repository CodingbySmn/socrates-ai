# socrates-ai
A webpage that resists with a timer before answering the questions, and reflects on human coginitive thinking

Socrates AI is a subversive, adversarial search engine that resists modern tech impatience by forcing users into a mandatory period of reflection before delivering answers. By deliberately breaking the industry rule of instant gratification, this materialized intervention exposes our toxic dependency on frictionless technology and reclaims the search bar as a space for human contemplation.
